## Common issues and fixes

| Problem | What to try |
|---|---|
| No voice at all | Check that **Voice** is set to **On** on the title screen and that your system volume is up. The voice is built into the game; if you still hear nothing, please report it and tell us your operating system. |
| The voice sounds robotic | The game could not play its built-in voice and fell back to the computer's own voice. Please report this (with your operating system) so we can fix it. |
| No music | Check that **Music** is set to **On** on the title screen and that your system volume is up. In a web browser, click once on the page first. |
| The music changed by itself | This is normal. Music follows the time of day: happy and upbeat from 6:00 AM to 5:59 PM, soft and sleepy from 6:00 PM to 5:59 AM. In a level it follows the level's time; on the menus it follows your computer's clock. |
| A hand moves too far | Each press moves one hour (short hand) or one minute (long hand). Holding the key keeps it moving, so let go a little sooner. If one short press moves more than one step, please report it. |
| Window is too small or too big | Press `F11` (or `Alt+Enter`) for full screen. The game scales to any window size. |
| Want to start over | Open **For Parents → Reset all data**. |
